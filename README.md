这里是逃逸速度（Escape Velocities）编辑部的一块自留地，也是一块虚拟飞地。我们将在这里上传一些汉译公开资源，由于众所周知的原因，它们无法在内网平台上发布。

然而，我们认为，这些思想与理论对于回应这个几乎同时是光怪陆离和驳杂深暗的时代有着深刻而持久的裨益。因此，它们能够以中文的形式存在本身就是一种激进性。

逃逸速度于2025年开始进行学术文献编译工作与少量原创写作，吸收了来自人文、社会与数据科学的人才参与供稿、修订和发布。我们主要关注人文社科的跨学科研究，以及它与科学技术可能产生的对话，并关注这些成果何以帮助我们理解共和国的过去与未来。
